Установка на Linux

Для .deb: sudo dpkg -i файл. Для .rpm: sudo rpm -i файл или sudo dnf install. Для AppImage: сделайте файл исполняемым (chmod +x) и запустите напрямую.

Установка APK

Разрешите "Установку из неизвестных источников" в настройках безопасности вашего браузера или файлового менеджера.
